# HKDSE Chemistry Paper Mapper

A Codex skill for analysing senior-secondary / HKDSE Chemistry assessment papers and producing a question-by-question mapping to the supplied HKDSE Chemistry chapter map.

## Use

Upload or provide:

- The chemistry question paper
- The HKDSE Chemistry syllabus or chapter/topic map

Then invoke:

```text
Use $hkdse-chemistry-paper-mapper to analyse this chemistry paper and map every question to HKDSE chapters and topics.
```

The skill outputs separate Markdown tables for MCQs and structured questions, plus a brief overall coverage summary.
